# SignalForge 策略筆記索引

這個資料夾專門保存 SignalForge 使用中的策略筆記。每一種已使用、已回測、已文件化或納入實驗流程的策略，都要有一份獨立筆記；新增策略或修改策略邏輯時，必須同步更新對應策略筆記。

## 筆記要求

- 一種策略一份筆記，檔名建議使用策略名稱，例如 `SMA Crossover.md`。
- 先解釋專業術語，再記錄策略假設、進出場條件、主要參數、已知限制與下一步。
- 使用 image generation 製作股價走勢解說圖，並在筆記中嵌入圖片，用來說明價格趨勢、進場、出場或持倉狀態。
- 圖片只作為策略說明，不代表績效保證；若策略仍在 research、backtest 或 dry-run 階段，必須在筆記中明確標示。

## 策略筆記模板

新增或更新策略筆記時，先讀 [[策略筆記撰寫框架]]，再依照該框架撰寫。不要在每份策略筆記中放回測紀錄型段落。
