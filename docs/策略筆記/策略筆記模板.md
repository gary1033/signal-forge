# SignalForge 策略筆記模板

每份策略、wrapper、overlay 或 portfolio gate 都用同一個 9 段流程。README 只放最短執行法；完整參數、用途、調參語意與最新刪減判斷都放在各自策略筆記。

```markdown
# <策略名稱>

## 快速定位

| 問題 | 答案 |
|---|---|
| CLI 名稱 / 參數 | `<name>` |
| 適用資料 | 日線 / intraday / 多股票 |
| 策略型態 | 單檔策略 / wrapper / overlay / portfolio gate |
| 實作位置 | `src\...` 或 `tools\...` |
| 參數入口 | `src\signal_forge\cli\strategy_options.py` 或對應 tool |

### 術語速讀

- 用 3 到 6 個 bullet 解釋讀這個策略必須知道的詞。

## 目前參數

| 參數 | 目前採用值 | CLI | 用途與調整判斷 |
|---|---:|---|---|
| `<param>` | `<value>` | `<flag>` | 說明調大 / 調小會影響交易數、反應速度、集中度、風險或資料邊界哪一面。 |

## 如何運行

精簡版只放必要參數；完整或調參版可放在這裡，不放 README。

## 進場流程

用表格或編號寫清楚每個判斷點的輸出與維護語意。

## 出場流程

寫清楚何時回到 flat、何時只是不再續抱，以及 wrapper 是否會主動平倉。

## 它想捕捉的 edge

用短段落說明策略假設，避免只列指標名稱。

## 股價走勢解說圖

![[assets/<strategy-image>.png]]

圖只做教學示意，不代表績效保證。

## 風險與限制

列出資料邊界、可能失效情境、不可誤讀之處與後續優化方向。

## 最新回測註記（YYYY-MM-DD）

| 指標 | 數值 | 解讀 |
|---|---:|---|
| 最新 artifact | `reports\generated\<artifact>.md` | 指向可重跑證據。 |
| 樣本 | `<股票池 / 日期 / 頻率 / 成本>` | 說明結果邊界。 |
| 核心指標 | `<value>` | 用一句話說明是否支持刪減判斷。 |
| 刪減判斷 | `keep / compare-only / discard` | 說明 tradeoff。 |
```
