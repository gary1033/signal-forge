# TradingView 開源腳本研究筆記

這份文件是 SignalForge 的策略研究入口。目標不是複製 Pine Script 後直接交易，而是把腳本背後的交易想法拆成可驗證的研究假設。

## 評估準則

每個腳本先用同一套問題檢查：

- **訊號是否清楚**：進場、出場、過濾條件能不能用程式明確表示。
- **是否容易重繪**：訊號是否依賴尚未收盤的 bar、未確認 pivot 或未來資料。
- **是否可跨市場驗證**：能不能拿到股票、ETF、期貨、外匯、加密貨幣上比較。
- **是否過度參數化**：參數越多，越容易只是在配合過去資料。
- **是否有風控**：停損、停利、倉位、曝險切換是否清楚。
- **是否可解釋**：虧損時能不能知道是趨勢失效、震盪失效，還是成交成本吃掉優勢。

## 第一期蒸餾規則

第一期只驗證進場訊號，不驗證完整交易系統。每個 TradingView 腳本先拆成以下欄位：

- 原始 Pine Script 與來源連結。
- 純多進場條件。
- short 條件、濾網、停損、停利、加碼與出場條件。
- 是否使用 `request.security`、pivot、未確認 bar 或可能 repaint 的訊號。
- SignalForge 對應策略與參數。

進場優勢驗證採固定規則：

- 訊號於 bar close 後成立。
- 下一根 bar open 進場。
- 固定持有 `hold_bars_per_day` 後，以 exit bar close 出場。
- 只測純多，short 訊號忽略並計數。
- Profit Factor 必須大於 1.2 才通過第一關。

## 類型一：均線趨勢策略

白話想法：短期平均價格站上長期平均價格，代表市場可能進入上升趨勢；反過來則偏弱。

優點：

- 非常適合當 baseline。
- 訊號簡單，不容易藏黑箱。
- 很容易測不同商品、不同週期。

缺點：

- 在盤整市場容易被來回洗。
- 進場通常比較慢，會犧牲一段行情。
- 20/200 這類固定參數不一定適合所有市場。

SignalForge 對應策略：`SmaCrossoverStrategy`。

## 類型二：VWAP 均值回歸

白話想法：VWAP 可以近似市場在一段時間內的成交量加權平均成本。價格離 VWAP 太遠時，可能有拉回平均成本附近的機會。

優點：

- 很適合日內交易與成本線分析。
- 可以自然轉成 z-score：價格離 VWAP 幾個標準差。
- 容易結合停損與出場規則。

缺點：

- 不同市場的 volume 品質差很多。
- 強趨勢市場中，價格可能長時間不回歸。
- 用 rolling VWAP 只是近似，跟 anchored VWAP 不是同一件事。

SignalForge 對應策略：`VwapReversionStrategy`。

## 類型三：多因子共振

白話想法：不要只相信單一指標，而是把趨勢、動能、成交量、位置等條件加總成分數。分數夠高才做多，分數夠低才做空。

優點：

- 很適合轉成 feature engineering。
- 可以清楚看到每個因子貢獻。
- 比單一指標更容易做研究報告。

缺點：

- 因子越多，越容易 overfit。
- 權重如果沒有紀律，很容易變成主觀調參。
- 分數高不代表有 edge，只代表條件同時成立。

SignalForge 對應策略：`ConfluenceScoreStrategy`。

## 後續要加入的類型

- RSI divergence：適合做反轉候選，但 pivot 訊號要小心延遲與重繪。
- Order block / SMC：可以先拆成區間偵測、回測區間、成交量確認，不要直接相信圖形標註。
- 價格密度 / value area：適合研究均值回歸與價格分布，但需要小心樣本窗口與趨勢市場。
- Macro/risk filter：不直接決定方向，而是控制策略是否應該降低曝險。
